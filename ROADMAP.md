# Roadmap

[Back to my homelab](README.md)

I plan to expand the server so it supports more everyday uses at home while continuing to learn about server administration.

- [ ] **Refine the setup for multiple users.** Improve accounts, permissions, and service access so more people in my household can comfortably use the server.
- [ ] **Add backups to another disk.** Set up scheduled backups of important files and application configuration to an additional disk, with a straightforward way to restore them.
- [ ] **Add self-hosted cloud storage.** Run a service for storing, accessing, and sharing personal files across devices.
- [ ] **Add photo backups.** Introduce a service for backing up photos from phones and keeping them organized on the server.
- [ ] **Introduce service monitoring.** Track service availability and health, with notifications when a service needs attention.
